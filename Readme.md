# Кекстаграм

Учебный проект [HTML Academy](https://htmlacademy.ru/intensive/javascript): сервис просмотра фотографий на чистом JavaScript. Можно смотреть фотографии других пользователей, фильтровать их и загружать свои с обработкой.

![Скриншот главной страницы](screenshots/main.jpg)

## Что реализовано

**Просмотр фотографий**
- Загрузка данных с сервера и отрисовка миниатюр по шаблону.
- Просмотр фотографии в модальном окне: лайки, описание, комментарии.
- Сообщение об ошибке, если данные не удалось загрузить.

**Фильтрация**
- «По умолчанию», «Случайные» и «Обсуждаемые».

**Загрузка своей фотографии**
- Выбор файла и предпросмотр.
- Изменение масштаба.
- Пять эффектов с регулировкой интенсивности слайдером.
- Валидация хэштегов и комментария с отдельными сообщениями об ошибках.
- Отправка формы на сервер.

Вёрстка выполнена по готовому шаблону курса.

## Стек

JavaScript (без фреймворков и сборщика), [Pristine](https://github.com/sha256/Pristine), [noUiSlider](https://refreshless.com/nouislider/).

## Как запустить

```bash
git clone https://github.com/AnastasiiaXX/2402573-kekstagram-2.git
cd 2402573-kekstagram-2
npm install
npm start
```

Проект откроется на http://localhost:3000 в браузере. Данные загружаются с сервера HTML Academy, нужен доступ в интернет.
